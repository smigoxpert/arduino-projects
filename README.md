# Arduino Projects

A collection of Arduino sketches for various hardware projects.

## Projects

| Folder | Description |
|--------|-------------|
| [`pomodoro_timer`](./pomodoro_timer/) | Pomodoro productivity timer with LCD, buzzer, and EEPROM persistence |

---

## Getting Started

1. Install the [Arduino IDE](https://www.arduino.cc/en/software)
2. Open the `.ino` file inside any project folder
3. Connect your Arduino and upload

Each project folder contains its own wiring and usage notes in the sketch header.
